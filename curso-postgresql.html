¿Por qué este curso?

Casi toda organización guarda su información en bases de datos. Aprender a diseñarlas y consultarlas con SQL te permite usar esa información con criterio, desde cero.

Toma de decisiones

Consultas, agrupaciones y agregaciones para convertir registros en respuestas.

Automatización

Vistas, disparadores y procedimientos almacenados para que los procesos se ejecuten solos.

Auditoría y control interno

Transacciones y bitácora de control para dar seguimiento a lo que ocurre en los datos.

Analítica de datos

Conecta PostgreSQL con R, Power BI y Python para llevar el análisis más lejos.

Sin conocimientos previos: parte de cero y avanza hasta un taller final de aplicación práctica, en el que usas las tablas que construyes a lo largo del curso.

Plan de estudios · 10 sesiones

  1. Sesión 1Fundamentos

    Introducción a bases de datos

    • Definición, funcionalidad y aplicaciones de las bases de datos en las organizaciones.
    • Tipos de bases de datos: relacionales frente a NoSQL.
    • Modelo entidad-relación: atributos, tuplas y relaciones.
    • Identificadores: llaves primarias (PK) y llaves foráneas (FK).
    • Introducción a índices y formas normales.
  2. Sesión 2SQL

    Fundamentos del lenguaje SQL e introducción a PostgreSQL

    • Qué es SQL y cuáles son sus tipos de datos nativos.
    • Clasificación de sentencias: DDL (definición), DML (manipulación), DCL (control) y TCL (transacciones).
    • Introducción al gestor PostgreSQL y creación de tu primera base de datos.
    • Sintaxis de SQL y configuración de conexiones.
  3. Sesión 3Tablas

    Creación y estructuración de tablas

    • Conceptos fundamentales de tablas, accesos y permisos.
    • Creación y gestión de esquemas y tablas en PostgreSQL.
    • Ciclo CRUD: crear, leer, actualizar y eliminar (Create, Read, Update, Delete).
    • Aplicación práctica de los tipos de datos en el motor relacional.
  4. Sesión 4Datos

    Obtención e importación de datos

    • Aplicación avanzada de sentencias DDL.
    • Vistas (views) para simplificar consultas.
    • Métodos y técnicas para importar datos desde archivos externos.
    • Ejercicios prácticos: construcción de las tablas base del proyecto final.
  5. Sesión 5Modelado

    Planteamiento y modelado de bases de datos

    • Profundización en formas normales (normalización).
    • Niveles de abstracción: modelo conceptual, lógico y físico.
    • Herramientas de diseño de bases de datos, con ejemplos en PowerDesigner y herramientas con interfaz gráfica.
    • Generación de datos artificiales y aleatorios para entornos de prueba.
  6. Sesión 6Consultas

    Consultas y funciones en SQL

    • Ejecución de sentencias DML y escritura de consultas (queries).
    • Orden léxico frente a orden de ejecución de una consulta.
    • Filtros condicionales avanzados: WHERE, operadores lógicos y de comparación.
    • Funciones nativas y manipulación de tipos de fecha y hora.
  7. Sesión 7Joins

    Sentencias de unión entre tablas (joins)

    • Relación de múltiples tablas en consultas SQL.
    • Tipos de combinaciones: INNER JOIN, LEFT JOIN, RIGHT JOIN y CROSS JOIN.
    • Cláusula USING y combinaciones verticales con UNION.
  8. Sesión 8Agregación

    Consultas avanzadas y agregación

    • Funciones de agregación: SUM, AVG, COUNT, MAX y MIN.
    • Agrupación de registros (GROUP BY) y filtrado de grupos (HAVING).
    • Estructuras condicionales dentro de las consultas (CASE WHEN).
    • Transformación de datos (reshape / pivot) y expresiones de tabla comunes (CTE).
  9. Sesión 9Control

    Facilidades para seguimiento y control

    • Manejo de transacciones y bitácora de control (COMMIT).
    • Creación y lógica de disparadores de eventos (triggers).
    • Declaración y uso de variables.
    • Introducción a la creación de procedimientos almacenados (stored procedures).
  10. Sesión 10Taller final

    Conexión con otras herramientas y taller final

    • Integración de PostgreSQL con entornos de análisis externos: R, Power BI y Python.
    • Procesos de reingeniería de bases de datos.
    • Desarrollo e integración del taller final de aplicación práctica.
